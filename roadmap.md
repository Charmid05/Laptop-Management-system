# Laptop Store Management System — roadmap

Retail operations system with a React frontend, Node API, and SQLite persistence.

## Foundation
- [x] Rebrand application shell and settings for laptop retail
- [x] TypeScript entity models (`src/types`)
- [x] SQLite API, seeded administrator, and role-aware navigation
- [x] Global customer search

## Modules
- [x] Login
- [x] Retail dashboard (sales, revenue, customers, low stock)
- [x] Customers (list, registration, profile, sales history)
- [x] Sales, payments, and receipts
- [x] Laptop inventory and suppliers
- [x] Purchase orders with atomic stock receiving
- [x] Repairs and warranty ticket tracking
- [x] Sales, customer, supplier, and inventory reports
- [x] Administration: users, roles, audit log
- [x] Store settings

## Left for the backend developer
- Automated browser and API test coverage
- M-Pesa / card payment integration (UI + data shapes ready)
- Serial-number-level inventory and warranty registration at point of sale
